## Condideraciones (para ***TODOS*** los talleres).

### Porcentajes

* Controles -> 20%
* Taller 1 -> 10%
* Taller 2 -> 15%
* Taller 3 -> 25%
* Taller 4 -> 30%

### Comunicación y dudas

* Las consultas deben realizarse por correo institucional o WhatsApp oficial.
* Situaciones especiales deben comunicarse con anticipación.
* Puede haber excepciones según la situación (previa justificación).

### Trabajo en Equipo

* Talleres en pareja o individual (2 personas maximo y recomendado).
* Los commits deben ser descriptivos y frecuentes (no todo en un solo commit).
* Los commits deben ser equitativos, no debe recaer la mayoría en un solo alumno.

* ***TODOS*** los talleres deben ser realizado mediante un repositorio (***PUBLICO***) de GitHub creado por los alumnos. No se aceptaran talleres que no tengan su repositorio correspondiente.
* El codigo debe estar correctamente documentado en cada funcion que se utiliza.

### Entrega

* Formato: Archivo .txt con link al repositorio GitHub.
* Nombre archivo: `nombreApellidoIntegrante1_nombreApellidoIntegrante2_TallerXPOO.txt`

    (reemplazar la `X` por el numero del taller).

* Contenido del .txt: 
````
Integrante 1: Nombre Completo - RUT - Usuario GitHub  
Integrante 2: Nombre Completo - RUT - Usuario GitHub  
Link repositorio: https://github.com/usuario/repositorio
````

### Estructura del repositorio

* Proyecto tipo ***Eclipse*** en la raíz (NO dentro de carpetas adicionales).
* README.md en formato Markdown.
* Archivo PDF con diagrama de clases (desde el segundo taller en adelante).

### Revisión

* Se revisará el último commit antes de la fecha de entrega estipulada.
* No se aceptarán entregas atrasadas (ni 1 minuto después).
* Solo una persona del grupo debe subir el archivo de entrega.

### Librerías Externas

* No se permite el uso de librerias que no esten especificadas en el enunciado de cada taller.
* En caso de querer/necesitar el uso de una libreria, debe ser consultado y esperar la autorización del ayudante.

### Documentación Obligatoria

* ***Readme.md***:
    * Descripción del proyecto.
    * Integrantes con RUT y usuario GitHub.
    * Estructura del proyecto (paquetes y clases principales).
    * Instrucciones de ejecución.
* ***Diagrama de Clases***:
    * Debe incluir TODAS las clases.
    * Notación UML correcta.
    * Relaciones claramente identificadas.

## Observaciones

Descuentos en caso de incumplir alguna de las consideraciones:

* Nombre de archivo incorrecto -> 10 décimas.
* Contenido de archivo incorrecto -> 10 décimas.
* Datos faltantes en las primeras 5 líneas -> 10 décimas.
* Proyecto fuera de la raíz del repositorio -> 5 décimas.
* Proyecto sin la estructura de Eclipse -> 5 décimas.
* Repositorio no existente -> 70 décimas.
* Uso de librerías no permitidas -> 70 décimas.
* Taller no enviado -> 70 décimas.
